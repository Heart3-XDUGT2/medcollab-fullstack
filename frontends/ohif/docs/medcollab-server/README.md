# MedCollab 前端开发交接包

> 2026-11-02 团队影像库增量：先读 [团队库与个人不可撤销共享](./team-library/团队系统接口.md)。该版本增加团队 API，并禁止个人共享撤销；旧的撤销说明不再适用。覆盖后按仓库的 scripts/build.mjs 重建并重启后端和网关。

版本：2026-11-01，当前统一入口部署（含底部折叠面板和掩码颜色空值修复）。

面向接手 Portal、Keycloak 登录外观和 OHIF 工作台的前端开发者。

1. 先读 [前端开发维护与兼容性指南](./前端开发维护与兼容性指南.md)：实际架构、全部当前入口、接口、字段语义、改动位置和兼容边界。
2. 查 [contracts.ts](./contracts.ts)：HTTP JSON、草稿和工作台界面的 TypeScript 类型。它是交接参考，不会自动改变服务器。
3. 看 [request-examples.ts](./request-examples.ts)：同源请求、动态 CSRF、身份复核、逐文件导入、冻结发布请求和二进制导出示例。现有项目优先沿用其适配器，不必引入第二套请求层。
4. 改完按 [兼容性验收清单](./兼容性验收清单.md) 检查。代码编译通过不能代替真实服务器读写核验。
5. 查全路径可用 [接口完整路径速查](./接口完整路径速查.md)，需要脚本读取时用 [接口索引.json](./接口索引.json)。该索引包含当前接口和明确标记的旧兼容接口，不是在线 Swagger。

本包没有账号密码、Cookie、令牌、患者影像、数据库、node_modules 或浏览器配置。所有示例编号均为占位值。

本文档是对本机当前实现的快照，不承诺尚未实现的实时画笔同步、审核角色、SR/RTSTRUCT 保存、任意文件存储或 STL/OBJ 导出。
