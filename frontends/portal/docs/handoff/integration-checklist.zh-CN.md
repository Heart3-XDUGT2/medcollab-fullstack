# 联调与交付检查单

日期：2026-11-01。

使用方式：按实际证据逐项勾选。迁移提交前的自动化结果由最终验收记录给出，下面未默认勾选的项目不代表已实现。

## 1. 新开发者能独立开始

- [ ] 使用本仓库锁文件安装，不需要旁边有 OHIF 或原开发者的绝对路径。
- [ ] 按根 README 的实际脚本启动，打开首页、账号入口与原密码外观预览。
- [ ] 类型检查、单元测试和生产构建通过，依赖不含 OHIF/Cornerstone 引擎。
- [ ] 使用明确动作进入示例；新建、搜索、筛选、重命名、概览、共享展示可操作。
- [ ] 示例刷新/退出后重置，不请求真实业务写入，不把文件选中当作上传成功。
- [ ] 桌面、平板、手机和弹层均验证；键盘焦点、关闭/返回、长名称没有迁移回归。

## 2. 后端首次接入

- [ ] 提供实际后端版本/提交、开发入口和两个普通账号；凭证不写仓库。
- [ ] 明确门户 URL、Java 代理 URL、Keycloak 入口和 Cookie 的 host/path/SameSite/Secure。
- [ ] 使用同一个主机名；避免 `localhost`、`127.0.0.1`、局域网 IP 混用。
- [ ] `/api` 返回 JSON；未认证不重定向成 HTML 登录页；错误不被 SPA 回退成 200 HTML。
- [ ] 真实 `/api/session` 与当前契约一致，包括匿名会话与动态 CSRF 字段。
- [ ] 每次写操作前正确取得当前会话，核对 issuer/subject，使用当次 CSRF 值。
- [ ] 正确处理 401、403、404、409、413、5xx、超时与未知结果；不盲目重试写入。
- [ ] 创建/改名及全部列表包裹符合文档，计数单位明确。

OpenAPI 是按交接整理的协作文件，不代表后端已经提供 Swagger 或已部署到文档里的示例地址。
原交接的 423 专门语义属于 SEG 编辑服务，仅在后续 OHIF/标注保存联调时另行确认，不是本轮 Portal 的编辑锁协议。

## 3. 真正的登录和退出

- [ ] 点击登录/注册通过浏览器导航进入 Java，不在 Portal POST 密码。
- [ ] Java OIDC 回调和 Keycloak redirect allowlist 指向约定入口。
- [ ] 成功登录能回到 Portal，而不是仍固定返回 8080 根路径。
- [ ] 退出完成 Java 会话清理与受信任的 IdP 退出跳转，不只是隐藏头像。
- [ ] 外观预览不冒充真实登录；验证默认适配器不发送或保存密码。
- [ ] 换账号后清理前一账号数据、待提交表单和迟到请求，不把其内容传给新身份。

## 4. 数据与共享

- [ ] 按真实 `owner/shared/public` 语义显示，创建者关系不冒充私密性或完整角色体系。
- [ ] 公共数据的访问范围、原图下载与分享规则由服务端真实执行。
- [ ] 可访问数据集的读取/重命名/共享操作与后端权限一致；不只隐藏按钮。
- [ ] 共享对象在搜索后失效，404 不被误判为整个数据集失权；请求取消仍有效。
- [ ] 移除自己或撤销共享后，列表和工作界面都不继续读取旧授权数据。
- [ ] 空集、零实例、请求失败、无匹配与无权限不是同一状态。

当前协议没有细分只读/可标注权限、密码分享或训练数据集完整业务模型。不能从页面演示推出这些服务端能力。

## 5. 上传与结果核对

- [ ] 非空、默认单文件不超过 1 GiB（1,073,741,824 字节），限制说明与后端部署一致。
- [ ] 验证数百 MiB 文件与 1 GiB 边界接受、1 GiB + 1 字节拒绝；两个各 600 MiB 的合规文件不因总和超 1 GiB 被拒绝，仍串行导入。
- [ ] 导入客户端期限 / 网关接收上限为 30 分钟，超时结果未知不重试；不把上传放宽等同于 SEG 或工作台源 CT 64 MiB 安全限制放宽。
- [ ] 创建/选择数据集后，逐文件 multipart，字段为 `file`、`datasetId`。
- [ ] 不手动覆盖 FormData boundary；按实际响应区分 `Success`、`AlreadyStored`。
- [ ] 中途失败保留已完成结果；取消不承诺撤销后端已完成的导入。
- [ ] 网络超时或响应异常归为结果未知，不把未知当成确定失败自动重传。
- [ ] 导入完成与影像可打开、索引完整、标注可保存分别验收。
- [ ] 不因调试下载/提交真实患者影像；样本需明确授权与脱敏。

## 6. OHIF 与部署

- [ ] 根据 `frontend-ohif-contract.zh-CN.md` 实现受控 launch，而不是把 datasetId 当 UID。
- [ ] 访问、标注与返回参数不作为可信授权信息。
- [ ] Portal 的资源路由、后端 API、OIDC 回调、OHIF base 路径互不抢占。
- [ ] 深链接刷新能打开对应应用，API 错误和资源不存在不被错误回退吞掉。
- [ ] 本地开发代理不是生产网关，不对任意用户开放；代理目标来自可信开发配置。
- [ ] 浏览器配置只有公开运行参数，没有密码、client secret、数据库或对象存储长期密钥。
- [ ] HTTPS、访问日志脱敏、缓存、备份和恢复按部署环境独立验证。

## 7. 迁移验收记录

最终结果应在仓库的迁移/验收说明中记录：

- 交付提交、基线 tag、远端分支和是否已推送。
- 实际运行的脚本、测试数量/结果、构建结果及截图位置。
- 真实后端是否启动、是否真正用两个账号联调。
- 仍待后端或工作界面团队实现的能力。
- 保留的上游许可证、字体与静态素材来源，以及公开发布前的未决事项。

“模拟协议测试通过”“页面截图正确”“构建成功”和“后端真实联调成功”是不同证据，不能互相替代。
