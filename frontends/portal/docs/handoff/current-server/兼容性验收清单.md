# 前端修改后的兼容性验收

> 2026-11-02 团队影像库增量：先读 [团队库与个人不可撤销共享](./team-library/团队系统接口.md)。该版本增加团队 API，并禁止个人共享撤销；旧的撤销说明不再适用。覆盖后按仓库的 scripts/build.mjs 重建并重启后端和网关。

日期：2026-11-01。按改动范围选择检查；不默认把未执行项目标记为通过。测试使用公开演示 CT 和隔离测试账号，不覆盖公共集的正式标注。

## 仅改排版、按钮、折叠、交互

- [ ] 当前实际登录用户名来自 session，匿名/过期不会显示假用户。
- [ ] 加载、空列表、搜索无结果、离线和无权限提示各自正确。
- [ ] 保存/发布/导出/加载的按钮仍调用现有 service，ready/busy 禁用规则保留。
- [ ] 折叠只隐藏内容；状态和错误入口仍可见，自动保存和轮询继续。
- [ ] 展开/收起可用键盘操作，焦点与 aria 状态正确，不误触 OHIF 全局快捷键。
- [ ] 桌面、小屏、长用户名/长错误不会遮挡主要操作；弹窗关闭和返回焦点正常。
- [ ] 面板显示“本机草稿”与“已发布/已共享”含义正确，未保存时不报成功。

## 改登录/注册主题

- [ ] 从正式 8080 登录/注册，实际看到修改后的 Keycloak 主题。
- [ ] 错密码、重复用户名、必填字段等服务端错误仍可见；表单 action/字段未破坏。
- [ ] 登录完成回到 Portal；错误参数可见；没有新增 `/api/login` 假接口。
- [ ] 退出同时清除 Java 会话并走允许的 Keycloak logoutUrl；重新登录账号正确。
- [ ] 不记录密码、Cookie、CSRF、client secret、OIDC code/state。

## 改 Portal API、导入或共享

- [ ] 新建名称和重命名刷新后仍保留，id 不变；列表 `Items.total` 与返回数组一致。
- [ ] 文件夹按 File 逐个 multipart，字段仍为 file/datasetId，不手工设置 boundary。
- [ ] 成功与 AlreadyStored 分别统计；同 UID 不同字节的 409 不覆盖。
- [ ] A/B 分别导入相同公开 CT，物理去重但私有影像集和命名独立，没有自动共享。
- [ ] 个人共享给 B 后 B 可读写和继续共享；撤销返回409且授权保留。团队移除成员后其团队访问被拒绝。
- [ ] 公共集无需共享；搜索使用 subject 作为目标 ID，2–100 字符规则保留。
- [ ] 超时、取消、5xx 的未知结果提示先核对，不自动重复创建/上传。
- [ ] 待上传/共享操作期间退出、切换账号、卸载页面，旧队列不继续向新上下文写入；迟到响应不污染新页面。

## 改工作台入口或数据源

- [ ] Portal 原“打开工作界面”打开选中集；单/多序列正确，没有误开样例。
- [ ] 真实工作台 network 使用 dataset-scoped DICOMweb，CT 没走 PNG preview。
- [ ] 在网络响应中核对 Study/Series/SOP、实例数量与源集对应。
- [ ] 业务 datasetId、Orthanc seriesId、DICOM UID 没有混用；仅有部分同 UID 切片时不会越权补齐。
- [ ] URL 中篡改 access/intent 不会绕过 Java；未授权账户、被移除的团队成员及已删除团队数据集的请求被拒绝。
- [ ] /home、/workspace、/imaging/medcollab/medcollab 的深链接刷新正确；未知 API 没变成 200 HTML。
- [ ] 返回 /home 后重新读会话/列表；未保存、保存中或发布中的离开提示保留。

## 改草稿、掩码、发布或导出

- [ ] 同一序列画两个标签、多个切片，等本机保存完成后刷新；像素、标签编号、名称、颜色和空间对齐恢复。
- [ ] 绘制并等待本机保存期间没有 Java 草稿 PUT 或发布 POST；IndexedDB 事务完成后才报已保存。
- [ ] 同账号两个标签页的 CAS 冲突可见；发布清空后的 tombstone 保留，旧页面不能复活旧草稿。
- [ ] 换账号不读出前一账号草稿；不同序列/影像集草稿不串；源指纹不匹配时不叠加。
- [ ] 空视图、切换布局、暂时没有颜色时不出现 null.slice，已知颜色和像素不会丢；新颜色再次可见时能保存。
- [ ] 发布完整 Labelmap，200 后读取 /labelmap 与 /file，重新打开可编辑；用独立 B context 加载版本结果一致。
- [ ] 两账号从同一旧版本发布，后者 409、草稿仍在；没有把旧草稿版本号直接改新再覆盖。
- [ ] 模拟请求已到服务端但响应丢失，重试同 publicationId/内容/版本只产生一次发布；结果不明时不允许改冻结内容。
- [ ] 保留本机草稿时收到共享新版本只提示；加载替换需要明确确认。
- [ ] 导出当前 Labelmap 得到 application/dicom；不会新增共享版本。已发布文件下载仍走 /file。
- [ ] 重开 DICOM SEG 核对 SOP Class/SegmentationType、源引用、标签、像素和空间方向。下载有文件本身不足以证明保存正确。
- [ ] 测量、箭头和三维显示没有被误报成已发布；未接入能力如实提示。

- [ ] Portal 的 typecheck/test/build 与受影响检查通过；OHIF 生产构建和相关回归检查完成。
- [ ] 区分 mock、真实服务器和正式 WSL 的证据，不用一类结果替另一类。
- [ ] 不把 OHIF 既有全仓类型诊断说成全部通过；说明与本次改动有关的失败。

- [ ] 说明是否改 HTTP 协议/IDB schema/路由/主题，有变化则同步迁移、文档和测试。
- [ ] 隔离 QA 账号和 QA 成品已清理；没有误发布测试标注到用户的公共 CT。
- [ ] 交付不包含账号密码、患者影像、数据库、浏览器配置、缓存或 node_modules。
