日期：2026-11-01。

结论：独立前端的本机迁移验收通过，可交付代码和后续联调基础。**没有完成真实 Java/SSO/OHIF 业务联调，不是生产上线验收。**

## 1. 迁移范围

源仓库：`Heart3-XDUGT2/medcollab-ohif`。

- `abe5bc8a4`：数据集首页、账号入口、上传/共享、适配器及测试。
- `a592c82d9`：原密码表单外观预览。
- 新仓库初始提交：`f6a56f9`。

新项目保留 React 18、TypeScript 和 React Router，使用 Vite 独立构建；版本、脚本与安装方式以根 `package.json`、`pnpm-lock.yaml` 和 README 为准。

没有迁入 OHIF monorepo、`@ohif/*`、Cornerstone、DICOM 解析/三维引擎、原 `node_modules`、影像数据或旧设计缓存。源码和测试扫描未发现依赖原开发者磁盘路径的导入。原 OHIF 工作副本保留原状，没有移走文件或回滚其功能。

## 2. 行为保持与必要差异

- 首页、筛选/搜索/排序、示例、概览、创建/改名、上传/共享展示和诚实错误状态保留。
- ui-next 替换为小型本地 Radix/Slot/lucide 兼容层，保留 ref、`asChild`、`data-cy`、弹层和菜单语义。
- 会话、动态 CSRF、身份核对、取消/generation、共享 404 二次核对、未知结果不自动重试等机制保留。
- 根路径与密码预览返回入口进入 `/home`，不伪装存在原生 Viewer。
- 新增受控 `publicSamplePath`，与业务 `workspacePath` 分开，默认均未配置且拒绝任意外站跳转。
- API 默认不启用；示例显式进入、只在内存中，不造真实账号或云端写入。

素材差异：

- 旧 CT 截图底层再分发条款未确认，本仓库不附带其像素或 DICOM；登录是完整无图布局，不留占位框、不编造患者。
- Inter 来自锁定的 Fontsource 包，保留 SIL OFL 1.1；没有分发系统中文字体。
- OHIF MIT 及上游版权保留，其他依赖许可见 `THIRD_PARTY_NOTICES.md` 与 `public/licenses/`。

## 4. 独立审查

源码审查没有发现实质 P1/P2 迁移回归，但不能代替运行测试。

主审在浏览器复现并推动修复了一项焦点问题：未预选行而从菜单打开重命名后，取消/Escape 曾把焦点留在 BODY。现在返回目标绑定稳定原行，已补 E2E，并手动确认焦点回到原数据集按钮。登录帮助弹窗 Escape 后也返回触发按钮。

新上下文截图评审确认可交付独立 UI 预览，没有必要返工项。手机首屏工具区可后续单独优化，本轮不重构布局。视觉评分只是内部主观参考，不证明真实登录、上传、性能或完整无障碍合格。
