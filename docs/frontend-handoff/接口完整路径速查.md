团队影像库新增接口：

| 方法 | 完整路径 | 用途 |
|---|---|---|
| GET | `/api/teams` | 我的团队 |
| GET | `/api/teams/search` | 搜索队名或完整 ID |
| POST | `/api/teams` | 创建团队并返回一次性可见邀请码 |
| POST | `/api/teams/join` | 凭团队 ID 与邀请码加入 |
| GET | `/api/teams/{id}` | 读取当前所在团队 |
| PATCH | `/api/teams/{id}` | 组长修改队名 |
| GET | `/api/teams/{id}/members` | 读取队内成员 |
| PUT | `/api/teams/{id}/members` | 组长直接添加已有账号 |
| DELETE | `/api/teams/{id}/members/{subject}` | 组长移除组员 |
| POST | `/api/teams/{id}/leave` | 普通成员退出 |
| POST | `/api/teams/{id}/transfer` | 移交给当前成员 |
| POST | `/api/teams/{id}/invite-code` | 组长轮换邀请码，旧码失效 |
| GET | `/api/teams/{id}/datasets` | 团队影像库 |
| POST | `/api/teams/{id}/datasets` | 创建团队数据集，当前账号记录为上传者 |
| DELETE | `/api/teams/{id}/datasets/{datasetId}` | 当前成员删除自己上传的数据集（软删除） |
