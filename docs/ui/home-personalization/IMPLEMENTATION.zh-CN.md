## 实施边界

- HomePage 保留既有会话、动态 CSRF、identity / generation / AbortController、取消、失权与写结果未知恢复逻辑。
- 新增无业务状态的 `DatasetCollection.tsx`，由同一个已筛选 / 排序数组呈现索引或清单。名称、来源和主操作固定；创建者、实例数、创建时间按个人显示偏好控制。
