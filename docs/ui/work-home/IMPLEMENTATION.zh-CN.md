日期：2026-11-03。状态：首批、唯一 P2 修正与一次定向确认完成；同一独立审查员裁定 `Disposition=ship`、P2 resolved。视觉与代码冻结；未提交、推送或部署。

## 实现范围

- `/home` 内提供工作首页 / 完整资料库切换，不重建资料业务状态；搜索、排序、选择、原布局与密度偏好保持。
- 新用户默认工作首页；已有无 `home` 字段的 v1 偏好明确兼容为原资料库入口，保留清单、密度、分组及字段。默认入口 / 模块显隐和顺序复用同一个账号本机偏好模型，严格白名单，不存资料 ID、姓名、医学内容、历史或凭证。
- 显式 URL scope / view 和当前上下文手动切换优先于迟到偏好；账号切换、退出演示时重新采用目标账号默认入口。
- 工作首页为继续、收藏、最近、资料库入口、本人团队五个可重排章节。核心入口和创建 / 上传不随隐藏全部章节而丢失。
- 真实继续入口只针对当前选择的数据集，不声称恢复精确序列、视角或草稿，也不将创建时间当访问时间。仍调用受控 `buildWorkspaceUrl`。
- 真实收藏 / 最近没有 API，显示未接能力，不调用需求草案路径，不写浏览器医学历史，不因打开按钮点击记成功打开。
- 演示收藏 / 取消、移除 / 清空最近均只在内存。最近时间来自明确标为示例的固定数据；刷新或退出清除演示更改。打开仍提示未接入，不产生虚假访问回执。
- 团队仅调用已有本人团队 GET；团队快捷 query 必须在重新读取的本人 membership 列表中匹配后才打开详情，不以 query 授权。演示不连接真实团队。
- 重复资料可出现在继续 / 收藏 / 最近；详情与操作弹窗保存实际 DOM 入口，关闭返回同一入口，不用业务 ID 假设页面只有一处。
- 保留既有 Cookie、新 CSRF、身份、取消、未知写入保护与 1 GiB 串行 FormData 上传。未修改后端、网关、OHIF 或运行配置。

## 单一统计接线

主页面只消费二号 `statistics/**` 的 `useAnnotationStatistics` / `DatasetCoverage`，不重复实现解析、健康能力判断、请求节制或缓存。继续目标 / 详情即时读取；资料库近视口按需读取，同一对象复用同一 model。

共享画布与已归档覆盖率分开呈现。紧凑摘要默认保留两种比例及必要状态，原生展开和资料概览可达完整分子、分母、归档说明与重读；继续目标 / detail 始终完整展开。不将覆盖率解释成质量、器官完整度或审核通过率。只用已有统计 GET，不下载 Labelmap。

`issue.resource=account` 的 401 / 403 走账号失效；已核对身份的 dataset / series 403 / 404 只清理对应数据集。若该资料的重命名、共享或追加上传弹窗打开，同时取消它自己的操作 scope、清除名称和摘要；等待中写入仍提示结果可能已发生，不称回滚、不自动重试。不清空无关弹窗、不刷新整个资料库形成循环。

旧服务缺统计能力不删除数据集。统计模块先探测公开 health，再在实际私有读取前后核对身份；模块验证细节见 [二号统计记录](statistics.zh-CN.md)。

演示 CT 分母在 `demo-statistics.ts` 独立显式列出，不由实例数计算。相容测试只核验合成单帧 CT 总数不超过该合成资料实例总数、空集为零、MR 无受支持 CT；这不是生产统计公式。
