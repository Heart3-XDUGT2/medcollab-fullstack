# 工作首页方向

日期：2026-11-03。模式：Operate。本地创作，不调用外部设计服务。

## 选择

比较三个组织方式：统计仪表墙容易将覆盖率误读为工作质量；纯收藏页无法容纳未接后端的真实状态；“工作索引”把返回资料的路径放前面、完整资料库作为稳定退路。本轮选择工作索引。

沿用灰白、湖蓝、近黑、Inter / 系统中文、零字距与短圆角。工作首页不是新的品牌世界：上方固定首页 / 资料库切换、创建与上传；主体是继续、收藏、最近、资料库入口、团队等可重排的平面章节，不把每个章节包装为浮动卡。

继续模块显示可辨认的数据集与服务器帧覆盖率；没有真实最近 API 时不推断“上次工作”。真实继续目标取当前选择，未选择时明确为“选择数据集”，不把创建时间当访问。演示继续取标明来源的示例最近记录。收藏 / 最近在真实模式显示接口未接能力，在演示模式提供完整内存交互。

三尺寸使用同一内容层级：桌面跨栏继续目标与并列工作章节；平板保留可读宽度的两列章节，手机收为单列，先入口和继续目标、再按本人顺序呈现其余模块。团队不被固定在某一视觉列，重排顺序与阅读顺序保持一致。长名称和分子分母是内容，不让装饰抢占空间。

## 调研依据

已读主报告及飞书、Teambition、Drive、OneDrive、Dropbox、Notion、Linear、Airtable、RedBrick AI 相关条目。借鉴工作入口 / 完整资料库分离、核心名称稳定、个人偏好可逆及模块明确作用域；不照搬工单状态或 Office 文件模型，不从论文推导效率提升。

沿用上一轮本地 Editorial greeting 节奏参考（seed 1841026147），保留品牌 palette/type，不新增问候英雄区、KPI 墙、假医学图或图板素材。

## 状态与边界

- 原资料库搜索 / 排序 / 选择与 v1 显示偏好保留。入口和模块配置也按本人本机保存，只存白名单枚举。
- 显式 scope 与用户主动切换优先于异步读取的默认入口。旧版 v1 清单偏好不被新默认索引覆盖。
- 重复资料入口保留各自 DOM 焦点，弹窗返回原入口，不用 ID 唯一性猜触发者。
- 统计只消费二号单一模块；不下载 Labelmap、不无限扇出、不持续轮询。0、未知、旧值、失权和缺能力分开。
- 演示收藏 / 最近源于固定合成示例，不因“打开”点击伪记成功，不读写真实业务或本机医学历史。
- 本轮首批截图交主审，合并发现后一次修正和确认，不自行追加审美循环。

## 收口

一次定向确认 12 张原图覆盖原六个清单场景和三尺寸完整 detail 证明。同一独立审查员逐张确认后裁定 **`Disposition=ship`、唯一 P2 resolved**；这只是截图结论，不替代真实权限、后端或临床验收。
