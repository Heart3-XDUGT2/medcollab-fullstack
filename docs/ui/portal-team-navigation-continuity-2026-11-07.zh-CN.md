# Portal 团队入口与导航连续性

日期：2026-11-07。基线：`main` / `3444d1d`。本次仅包含 Portal 与测试，不改变后端、OHIF、依赖、数据库或部署。

## 实现范围

- 工作首页、个人资料库、团队索引和团队详情共享持久的 Portal header、内容框架、字体与响应式边界；团队业务布局和登录页仍保持独立。
- 导航使用可中断的标记移动与当前内容短暂色调过渡；遵守 reduced-motion，不锁定控件、不改写导航历史。仅保留几何，不保留退出页面、截图或旧用户内容。
- 页面仍负责身份、请求与取消生命周期，路由离开立即卸载；个人页 401/403 同步清除旧账号名。
- 团队资料收藏复用现有服务器 API，不复制资料、不赋予权限。团队切换、换账号和失权清理旧上下文，未知收藏状态不可盲写，未知写入结果不自动重试。
- 首页团队来源入口选择具体团队后进入独立团队库，不遍历所有团队拼接结果，也不声称已接入统一服务端分页。
- 上传在创建数据集之前拒绝已知不支持的文本、图片、文档等格式，混选批次一起预检。保留无扩展名、未知后缀及 DICOM MIME 候选；预检不是 DICOM 内容认证，服务器仍做最终校验。
- 保留个人独立转发副本、个人/团队删除权限、已有显示偏好与 URL/back/home-return 行为。

没有复制 Uiverse 实现或新增第三方视觉资产。

## 验证与限制

最终本地验证：TypeScript、394 项单测、185 项完整浏览器回归，以及正式单入口产物的 66 项确认通过。测试覆盖共享 header 同一节点、立即移除旧 main、快速导航、中间动画状态、back/forward、减少动态、四种宽度，以及团队收藏身份/权限与上传批次边界。

业务 API 由合成夹具拦截；这些结果不代表真实用户上传、收藏写入、删除、转发或团队解散联调通过。低端硬件实际表现未经验证。

后端基线已经提供统一资料库与团队解散协议，但本前端提交不新增这两项界面；个人资料复制到团队也不在本次范围。创建数据集与逐文件导入仍是独立请求，后续内容校验失败可能留下真实空集，不宣称原子回滚。
