# Portal 首页迭代说明

日期：2026-11-06。状态：本地迭代提交至草稿 PR，待验收；不是生产部署或完整后端联调声明。

## 本次范围

- 将已采纳的研究交接台方向接到正式首页，继续使用真实会话、数据集、活动和统计模型，不导入设计探索组件。
- 保留 URL 入口/来源与浏览器前后退；从团队返回时仅在核对同一账号后恢复内存中的搜索、排序、选中和滚动状态。
- 首页提供资料清单默认布局；已有卡片、对比表格、密度、字段、分组、模块顺序及显隐偏好继续有效。
- 修正稀疏集合宽度、宽屏空间和图标目标对齐，维持移动端、长名称、焦点及减少动态状态。
- 上传入口对 NIfTI 提前给出不支持提示，不转换扩展名，不宣称已实现 NIfTI 导入。
- 活动功能以服务的 `homeActivityApi: "v1"` 声明为准；旧服务不发送缺失接口请求。收藏和最近列表失败隔离；未确认收藏状态禁止收藏写入。
- 集合接口 404 与数据集作用域写入 404 分别提示接口不匹配和资源错误；保留新鲜身份/CSRF、取消边界以及未知写结果不自动重试。

没有引入 Uiverse 组件源码或新视觉素材，也没有新增依赖。现有品牌、字体、图标的许可记录继续保留。

## 验证与边界

本地迭代完成 TypeScript 检查、373 项单测、153 项浏览器回归，以及清洁生产产物的 29 项确认。浏览器使用合成协议夹具并阻断未模拟的业务请求，不等同真实账号的后端读写联调。
