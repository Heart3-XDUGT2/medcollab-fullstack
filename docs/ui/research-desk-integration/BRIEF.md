## Direction Contract

THESIS: Resume an accessible research object, then scan the dataset directory.
Object names lead; scale, creation time and CT readings help identification.

OWN-WORLD: White working plane, mist-green continuation surface, charcoal
commands, lake-blue CT data, moderate CJK-first type, stable aligned metadata
lanes and a quiet reference stream. No medical thumbnails or decorative motion.

STORY: A current object can come from a selection or an actual recent record.
The user can open it, inspect it, choose another authorized object, scan personal
sources, or reach real activity and independent team libraries.

FIRST VIEWPORT: Three top destinations; page heading with existing create,
upload, home settings and refresh. The default desktop composition has
continuation/directory at left and recent/favorite/team references at right.
On phones the default main content precedes reference streams. Extra real
controls, source semantics and the no-annotation-recovery notice remain visible.

FORM: The user-approved A preview's conference-programme alignment discipline,
seed `b9ee4cb0`. No new roll. Name, context, data reading and action have distinct
jobs. A selected record retains focus-managed detail and real menu actions.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## Integration Truth

- Use existing HomePage/API, activity, StatisticsModel and authorized datasets,
  not the preview component or its synthetic arrays.
- Preserve identity/CSRF/cancellation/unknown-write boundaries, URL/back/return
  memory, old saved preferences, explicit demo, all activity states/paging and
  independent team routing.
- New default order is continuation, library, recent, favorites, teams; desktop
  references use a right rail. Existing explicit saved order and hidden settings
  remain authoritative and use normal document flow.
- Index presentation is now aligned object records. Comparison list, density,
  grouping and optional metadata continue to be real controls.
- Work-directory and full-library queries are separate in memory; same-identity
  team return restores both, with no query persisted to URL/history/storage.
- Current/archive frame counts, applicability, stale/error states and pending
  operations come from the same existing statistics snapshot. Multiple
  appearances share its existing resource model.
- Original preview at 60835 and its build remain intact. No backend, OHIF,
  API contract, dependency, database, login service or gateway configuration
  changes belong to this adoption.

## Evidence Scope

Gateway 8080 is used only as an existing static server for intercepted frontend
tests. Mocked reads/writes do not demonstrate live authentication, authorization
or clinical correctness. Final production build removes temporary multi-entry
test harnesses. No new raster assets are shipped.
