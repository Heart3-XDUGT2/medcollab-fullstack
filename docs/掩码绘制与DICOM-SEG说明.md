# 极简掩码绘制与 DICOM SEG

2026-11-01：草稿已从 Java 改存浏览器 IndexedDB，成品由 Java 检查权限后写入 Orthanc。

入口：http://127.0.0.1:8080/annotation-demo 。登录返回 Portal 后再打开此地址。

1. 点“浏览”打开 CT 并绘制，最后一笔后约 650ms 自动保存。
2. 等待“本地草稿已保存到 IndexedDB”后，可刷新并打开同一 CT 继续编辑。
3. “保存私有草稿”只保存此浏览器，不发 Java 请求。
4. “保存并上传”才发送完整掩码，生成标准 DICOM SEG 存入 Orthanc；其他有权限用户只同步已上传版本。

未上传草稿只在当前浏览器、当前网站地址下。换电脑、浏览器、端口或清除网站数据后无法从服务器恢复。

旧 Java 草稿会先持久化到 IndexedDB，再清除服务器旧记录。旧接口不再接收新草稿。上传失败、版本冲突、浏览器空间不足时都会保留可恢复的内容并显示提示。

当前仍为普通单帧 CT 的单区域 BINARY DICOM SEG 演示，原 CT 不变。OHIF 新工作台尚待后续接入。

完整接口和本地存储契约见 [使用与前端接入说明](legacy-local-task/outputs/indexeddb-drafts/使用与前端接入说明.md)。首次升级运行其中列出的启用脚本，之后仍可用桌面 01 或 14 启动。
